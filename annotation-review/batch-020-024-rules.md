# 第 20-24 篇注音補正規則

本文件只針對 `batch-020-024.md` 這一批五篇故事，作為人工補注音時的工作規則。目的不是逐字硬填，而是把可重複使用的讀音整理成「詞級規則」。

本批故事：

1. 大分事件
2. 太平洋上的一彎明月—蘭嶼的拼板舟
3. 六堆精神
4. 切膚之愛—蘭大衛
5. 先民灌溉的智慧

## 一、已確認規則

### 拉荷阿雷

使用詞級覆蓋，不逐字分散補。

```json
{
  "term": "拉荷阿雷",
  "zhuyin": ["ㄌㄚ", "ㄏㄜˊ", "ㄚ", "ㄌㄟˊ"],
  "pinyin": ["lā", "hé", "ā", "léi"],
  "reason": "大分事件人名；荷音同合"
}
```

規則：

- 凡是完整出現 `拉荷阿雷`，都套用此讀音。
- 表格中落在 `拉荷阿雷` 內的 `荷`、`阿` 不再逐字詢問。
- 若上下文只是包含 `拉荷阿雷`，但待確認字不是人名內的字，例如 `從拉荷阿雷` 的 `從`，仍需另外判斷。

### 來看

使用詞級覆蓋。

```json
{
  "term": "來看",
  "zhuyin": ["ㄌㄞˊ", "ㄎㄢˋ"],
  "pinyin": ["lái", "kàn"],
  "reason": "大分事件語境；看為四聲"
}
```

規則：

- `來看` 中的 `看` 讀四聲 `ㄎㄢˋ` / `kàn`。
- 後續遇到 `看到`、`看診`、`看著` 不直接沿用 `來看`，應各自以詞級判斷。

## 二、這五篇的補音策略

### 1. 先補專有名詞

這五篇有大量人名、地名、族名、機構名。這類詞如果逐字補，會造成重複工作，也容易誤判。

優先補完整詞：

- 人名：例如 `拉荷阿雷`、`阿里曼西肯`、`夏曼`、`藍波安`、`朱一貴`、`蘭大衛`、`周金耀`。
- 地名：例如 `拉庫拉庫溪`、`蘭嶼`、`六堆`、`彰化`、`嘉南`。
- 族名與文化詞：例如 `布農族`、`達悟族`、`拼板舟`。
- 機構名：例如 `彰化基督教醫院`、`嘉南農田水利會`。

人工回覆格式建議：

```text
詞：阿里曼西肯 = ㄚ ㄌㄧˇ ㄇㄢˋ ㄒㄧ ㄎㄣˇ / ā lǐ màn xī kěn
```

若只知道其中一字讀音，可先回：

```text
曼，音同慢
```

但系統整理時仍應盡量擴成完整詞。

### 2. 再補常見動詞片語

多音字常出現在動詞片語中，應補詞，不補單字。

本批需要注意：

- `來看`
- `看到`
- `看診`
- `看著`
- `說是`
- `勸說`
- `聽到`
- `跑到`
- `將傷害`
- `降低`
- `分為`
- `分線`
- `排水`
- `倒入`

規則：

- 相同字在不同詞中讀音可能不同。
- 使用者若補的是單字，系統應回看上下文，優先擴成 2 到 4 字詞。

### 3. 同一詞只問一次

`拉荷阿雷` 在〈大分事件〉中重複出現很多次。這類詞第一次確認後，應自動套用全篇，不再逐列要求。

第二輪輸出時，應改成：

```text
已套用：拉荷阿雷，共 N 次
仍待確認：阿里曼西肯、拉庫拉庫溪、呼頌……
```

避免讓人工在表格中重複填同一個答案。

### 4. 原住民族語、外文、羅馬字要保留

本批中會出現羅馬字或族語轉寫，例如：

- Istasipal
- Huson
- ARA
- Tao / 達悟相關詞

規則：

- 羅馬字本身不加注音。
- 羅馬字附近的漢字若是音譯人名，採完整詞級覆蓋。
- 不確定的族語讀音不以華語硬猜。

### 5. 日期與數字單位暫不優先

如 `2月23日`、`11時30分`、`45度角`，目前報告可能把 `日`、`分`、`度`、`角`列出。

規則：

- 日期中的 `日` 通常可建立通用規則。
- 時間中的 `分` 通常可建立通用規則。
- 角度中的 `度角` 可建立詞級規則。
- 但第一輪人工校對先優先處理會影響理解的人名、地名、動詞片語。

## 三、五篇分篇注意事項

### 大分事件

優先處理：

- 布農族人名：`拉荷阿雷`、`阿里曼西肯`、`呼頌`。
- 地名：`拉庫拉庫溪`、`莫庫拉蕃社`、`新武呂溪`、`荖濃溪`。
- 動詞片語：`來看`、`勸說`、`跑到`、`將傷害`、`降低`。

已完成：

- `拉荷阿雷`
- `來看`

### 太平洋上的一彎明月—蘭嶼的拼板舟

優先處理：

- 族名：`達悟族`。
- 人名：`夏曼`、`藍波安`。
- 文化詞：`拼板舟`、`飛魚`。
- 動詞片語：`看到`、`獵捕`、`製造`、`供作`、`挑選`。

注意：

- `夏曼` 反覆出現，應一次確認後全篇套用。
- `我` 在童謠引文中大量出現，可考慮建立高頻單字預設讀音。

### 六堆精神

優先處理：

- 專名：`六堆`、`朱一貴`、`李直三`、`侯觀德`。
- 地名：`內埔`、`下淡水溪`、`東港溪`、`阿猴城`。
- 事件名：`朱一貴事件`、`林少貓事件`。
- 動詞片語：`分為`、`並設立`、`將義勇民團`、`更促使`。

注意：

- `六堆` 大量重複，應以詞級方式確認，不逐字補 `六`。

### 切膚之愛—蘭大衛

優先處理：

- 人名：`蘭大衛`、`蘭醫生`、`林燕臣`、`林茂生`、`周金耀`。
- 地名與機構：`彰化`、`臺南`、`神岡`、`彰化基督教醫院`。
- 動詞片語：`看診`、`看到`、`轉而`、`應其子女`。

注意：

- `看診` 和 `看到` 都不是 `來看`，需分開確認。
- `彰化` 大量重複，應做詞級覆蓋。

### 先民灌溉的智慧

優先處理：

- 機構名：`嘉南農田水利會`。
- 水利詞：`分線`、`排水`、`水龍車`、`水圳`、`埤塘池潭`。
- 工程詞：`倒入`、`45度角`、`沉降`、`排程`。

注意：

- `分` 在 `分線`、`分支`、時間 `分` 中讀音語境不同，要補詞。
- `排` 在 `排水`、`排程` 中可用詞級規則處理。
