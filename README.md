## ✨ 網站特色 (Features)

* **專為自學者設計**：乾淨、易讀的介面，降低非母語人士的閱讀門檻。
* **全站注音標示**：故事內文皆附有清晰的注音符號，幫助學習者掌握正確發音。
* **優美開源字體**：採用專為教育與閱讀設計的開源字體，確保漢字與注音的排版美觀且易於辨識。
