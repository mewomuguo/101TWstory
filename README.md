# 臺灣小故事101｜101 Taiwan Stories


整理 101 篇臺灣在地故事，提供 **注音輔助閱讀、自適應版面設計、最近閱讀紀錄** 等功能，讓使用者能以更低門檻、更適合行動裝置的方式，自主閱讀臺灣故事。

網站連結：

---

## 專案定位

**臺灣小故事101** 以自學閱讀為主要使用情境，適合想認識臺灣文化、練習漢語閱讀，以及需要注音輔助的使用者。

本網站將故事內容整理為更適合線上閱讀與自主學習的形式，方便讀者使用手機、平板或電腦閱讀。

---

## 本網站特色

### 1. 注音輔助閱讀

故事文本加入注音輔助，降低閱讀門檻。  
適合學生、漢語學習者、親子共讀，以及需要注音輔助理解文本的讀者。

### 2. 自適應版面設計

網站支援不同螢幕尺寸，包含手機、平板、筆電與桌機。  
使用者可以在不同裝置上保持穩定、清楚的閱讀體驗。

### 3. 最近閱讀紀錄

網站會保留最近閱讀過的故事，讓使用者可以快速接續先前的閱讀進度。

---

## 故事分類

將 101 篇故事整理為四大主題：

- 島國意象
- 族群歷史
- 本土藝文
- 打拼精神
